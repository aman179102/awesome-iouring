# Contributing to Awesome io_uring

Contributions are very welcome!

### Submission Guidelines

1. **Relevance**: The project or resource must directly involve or optimize Linux `io_uring`.
2. **Quality**: Projects must be active, well-documented, and stable.
3. **Format**: Add new entries in alphabetical order under the appropriate section using standard markdown:
   ```markdown
   - [Project Name](https://github.com/org/repo) - Short 1-2 sentence description highlighting its io_uring feature.
   ```
4. **Pull Request**: Submit a clear PR description explaining why this resource benefits the systems community.

Thank you for helping maintain the highest quality `io_uring` resource index!
